# Slotbook app

This is the Next.js App Router client for the Slotbook protocol. Run it from this directory:

```sh
npm install
npm run dev
```

The docs API is generated by `npm run docs:generate`. It prefers the canonical Anchor IDL at `../target/idl/slotbook.json`; before the first successful `anchor build`, it bootstraps the instruction list from `../programs/slotbook/src/lib.rs` so the docs are still available during development.

Once the program build is available, the intended CI sequence is:

```sh
anchor build
cd app
npm run docs:generate
npm run build
```

Anchor's IDL is the source of truth for generated signatures and accounts. The explanatory meanings use the instruction docs from the IDL when present, with the protocol descriptions in `scripts/generate-program-docs.mjs` as the interim source until those Rust docs are emitted.
